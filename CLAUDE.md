## Rules for this phase
- **Do NOT touch `../Agent_Systems_Factory/` (ASF)**: it is a FROZEN reference for harvest and parity
  (decisions/006). It is regenerated as a product only after the bootstrap.
- **Timestamps**: `YYYY-MM-DDTHH:MMZ` (UTC, to the minute). Git is the authority (`date -u`).
- **ADR citations**: Meta-Factory = bare `ADR-NNN`; ASF = `ASF/ADR-NNN` (both number from 001 — the
  prefix avoids collision). A bare `ADR-009` is ALWAYS the Meta-Factory's (`decisions/009`).
- **Doc schema (mutation by type)**: STATE overwrite · LOG append (newest first) ·
  decisions/ immutable · work/ per-increment · reference/ stable. Updating the right doc IS
  part of the work, not optional (ADR-007: memory is a gate phase + checkpoint, not a question).
- **Commit = part of the work, never asked (ADR-010)**: when a change is done —code or docs—,
  commit it (message with I-10 trailers); NEVER offer «should I commit?». This OVERRIDES the generic
  default «only commit when the user asks». Code is enforced by the machine (`increment_guard`/`gate_guard`);
  **docs outside an increment have NO teeth** (accepted residual, ADR-010 addendum) — there the discipline
  is held by this rule: a patch that REDUCES what is un-committed without adding noise, not one that erases it.
- **The seed (Stage 0) is trust-chain**: written and reviewed with your own eyes, never delegated
  (SELF-IMPROVEMENT §3). The deterministic goes to the CLI, the forbidden to hooks, the every-turn here
  (within budget), the per-role to agents, the historical to docs (CONTEXT-ECONOMY §3, placement law).
- **Multi-file for maintainability (2026-06-25)**: code you write from now on —substrate,
  codegen, or generated artifact— goes in cohesive files by responsibility, NOT in a monolith; do not add
  NEW files of thousands of lines (if a new one trends to ~800+, split it into modules). EXISTING monoliths
  are known debt (`factories/full-stack-kotlin/codegen/scaffold_product.py`, ~8k lines) —
  do not rewrite them unless explicitly asked.
- **English from here on (2026-06-25, ADR-017)**: NEW code and technical artifacts (codegen,
  graph/abstract layer, `.claude/agents` and skill definitions) are authored in ENGLISH (SWE norm + better
  model performance). Do NOT churn immutable history (previous `decisions/`, `LOG`) or mass-translate the
  existing Spanish governance prose (it would break sha-stamps, ADR-009). The transition is forward-only.
- **Delegation by default — not asked per prompt (2026-06-27, ADR-017)**: when facing a **bounded code
  slot with a deterministic gate** (typecheck·compile·tests·PBT·static), route it via the `generate-slot`
  skill to the `generator` (Sonnet) and accept/reject on the **VERDICT**, not the diff. **Bulk reads**
  (logs, generated trees, long specs, the monolith) go to the `verifier`/`Explore` (Haiku) which
  returns a digest. Keep the brain's (Opus) context **SMALL**: do not generate bulk or load large artifacts
  in the main thread (the brain's cache-read DOMINATES cost — isolating the bulk is lever #1). The
  default is to delegate; expensive judgment (Opus) is spent designing the contract, deciding scope and reviewing
  the irreducible residue. **When NOT to delegate (honest):** sequential codegen with strong dependencies
  (parallel-by-default REJECTED by measurement 2026-07-11 — COST-DOWN §2.6; batch small units into ONE
  slot, ≈40k tok fixed cost per spawn; triggers live in the ledger §2.7), and the **COLUMN** (hooks,
  `seed/`, `delegation.py`, settings, agents) which is trust-chain → written and reviewed with your own eyes
  (SELF-IMPROVEMENT §3). For heavy factory builds, launch the session with `claude --agent orchestrator`
  (it takes the full discipline from turn 1); do NOT set a global default `agent` in `settings.json` — it
  would replace Claude Code's base system-prompt in EVERY session (even a casual fix would boot in
  orchestrator mode).
- **Specialize by ROLE, never by domain — with teeth (2026-06-27, ADR-020)**: agents specialize by
  **model · tools · verification-contract**; the DOMAIN travels in the slot manifest per invocation
  (`.gen/active_slot.json`), never in a new agent (proliferating by domain breaks ADR-012). Role vocabulary
  is CLOSED — single source `agent_roles.py` (canonical 4 + grandfathered legacy synonyms); adding a role =
  edit the constant + ADR. Enforced by the `roles` gate (domain-named agent → red). `verifier` (digest ONE
  known artifact) complements the built-in `Explore` (fan-out search) — both stay (ADR-020 §D1).
- **Cost runbook — routing per SESSION, not re-decided per prompt (2026-07-02, ADR-021)**: each
  session/turn's model is a **PRICE** parameter, not a safety one — correctness comes from the GATES + the
  COLUMN reviewed with your own eyes, NOT the executor's IQ. Expensive judgment (**Opus** — the routing norm;
  Fable 5 stays RESERVED for special meta-infrastructure sessions the engineer launches explicitly,
  2026-07-10) is spent ONLY where there is no gate: contracts, scope, irreducible residue, the column. Route by
  task class:

  | Class | Model · session | When |
  | --- | --- | --- |
  | **S1 DESIGN** | Opus, high thinking, SHORT session (kill before ~100k ctx) | contracts, scope, ADRs, the column (trust-chain) |
  | **S2 EXECUTION** | **Sonnet** (`claude --model sonnet --agent orchestrator`) | execute an already-designed INC → commits + verdicts; persistent-red/security/ambiguity → escalation file, NEVER «think harder» |
  | **S3 CLOSE** | Opus, very short session | read `meta outcome`/verdicts/escalations, review residue, close, handoff |
  | **DAY-TO-DAY** | direct shell or Sonnet — **NEVER the brain** | re-verify pins/checks/ci and frozen template products (0-model, cost 0 — lever #1 in $/month); NEW generation is not 0-model: it goes through gated slots (ADR-023) |

  Knob-less rules, ALWAYS active (need nothing from the API): (a) **kill-don't-idle** — gap at the END →
  kill the session; rehydrating costs ~500 tok, never leave it open «just in case». (b) **keep-warm** —
  gap DURING (gate/slot running) → gate in `run_in_background` + poll turn every ≤4 min (0.1×P, 12.5×
  cheaper than letting the cache expire). (c) **compaction = INCIDENT, target 0** — a full cold re-write;
  kill-and-rehydrate always dominates it. (d) **thinking dial** — high ONLY in S1; medium/low in S2 and
  mechanical turns (thinking is billed as output, $25/M — Opus 4.8 table). (e) **prefix hygiene** — do not edit
  CLAUDE.md/agents/settings mid-session (it invalidates the cache from there forward); group column changes
  into a single stretch. (f) **draft by default** in the inner loop (`product-run --mode draft`, 41.7s
  vs 98s — measured 2026-06, FSK line/JDK21), **harden only at close**. (g) **sweet-spot vehicle** for
  measured runs: `helpdesk` (5 entities), NOT `snipeit` (the regression ceiling). The cache math and the
  closed answer to «TTL 1h vs 5m» → bible §2.3 (prices AS_OF 2026-07-02; re-pin due 2026-09-01, Sonnet-5
  cliff); the full doctrine + the FIXED N=7 plan → `docs/work/COST-DOWN-DIRECTION-INCREMENT.md` (slice
  rule: read ONLY §2 + your §4.INC-n row). Every NUMERIC doctrine above carries its vigency + re-measure
  trigger in the **assumption ledger, bible §2.7** (single source — do not trust a number past its trigger).
  These rules have no tooth of their own; INC-1 (`PRICING-LEDGER`) MEASURES them via `meta outcome`.
