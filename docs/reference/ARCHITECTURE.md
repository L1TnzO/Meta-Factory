## 1. Terminology

- **Meta-Factory**: the platform described here. Its product is *factories*. It resides at the root.
- **Factory (product)**: a system generated by the Meta-Factory that, in turn, manufactures
  artifacts of a domain (ASF manufactures agents; a Full-Stack-Factory would manufacture web apps).
- **Factory-product**: what a factory produces (an agent, an app). The Meta-Factory does not
  touch them directly; it governs them *transitively* through the factory.
- **Factory-spec**: the SDD specification that defines a factory. Two halves (§5).
- **Factory production substrate**: the 13 cross-cutting invariants that every trustworthy factory
  needs, independent of the domain it manufactures (§3).
- **The anti-rubber-stamp column** (inherited from ASF/ADR-006): the three locks that make it
  impossible to mark a gate without real proof. The heart of trust.
- **Verdict bus**: the contract by which every expensive operation returns a verdict
  ≤N lines + a pointer to the artifact; the raw log never enters the orchestrator's context.
- **Seed**: the minimal trust kernel, hand-audited and frozen, from which everything else
  derives its trust (§7, Stage 0).
- **Meta-station (Mk)**: the atomic unit of the line that builds a *factory* (§6).
- **Deterministic shadow** (ASF/ADR-023): for every narrative obligation that must not be
  skipped, a hook/CLI that detects or prevents it. The narrative substrate declares; the
  deterministic one guarantees.

## 2. Three build contexts (ASF had two)

ASF distinguished **factory build** vs **product build**. The Meta-Factory
adds a level and renames them to avoid confusion:

| Level | What is built | Owner | Determinism mechanic | Frequency |
| --- | --- | --- | --- | --- |
| **N2 — Meta** | the Meta-Factory itself | platform engineering + Claude Code, governed by the **frozen seed** | the column + the two verifiers applied to itself (fixed point, §7) | low |
| **N1 — Factory** | a factory (ASF, Full-Stack) | the Meta-Factory's meta-station line, operated via Claude Code | meta-stations M0–M8 with gates | medium (one per factory + every template update) |
| **N0 — Product** | an agent / an app | *that factory's* station line | that factory's station model (inherited from ASF) | high |

Principle that cuts across all three levels (from ASF, generalized): **each level is verified by a
layer at least as trustworthy as itself; self-modification of the trust chain is gated by
re-derivation from the immediately more trustworthy layer** (§7, `SELF-IMPROVEMENT.md`).

## 3. The factory production substrate (the 13 invariants)

This is what ASF discovered —the hard way— that EVERY trustworthy factory needs, no matter
what it manufactures. It is the analog, one level up, of ASF's "seven production capabilities."
**The Meta-Factory bakes these 13 into every factory it emits, verified by construction.**

| # | Invariant | What it guarantees | Origin in ASF |
| --- | --- | --- | --- |
| I-1 | **Anti-rubber-stamp column** (3 locks) | the `passed` verdict is computed only by a deterministic verifier from real exit codes; test artifacts are immutable to the model; a `Stop` hook re-runs verify | ASF/ADR-006 |
| I-2 | **Stations as data** | the line is a sequence of YAML, not branches in code; zero hardcoded domain identity | §9.1, anti-pattern #4 |
| I-3 | **Determinism frontier** | model for the creative part (bounded slots), code for the invariant part; determinism lives in process+verification+contracts, never in the generated content | PF-1/PF-2, ASF/ADR-009 |
| I-4 | **A/B/C automation ladder** | automatic / draft+consent / provisional-with-honesty; never "block or fabricate" | ADR-010 |
| I-5 | **Generated/domain boundary** ⚠️ **AMENDED by `ADR-011`** (2026-06-15): 100% is generated, there is NO human `domain/` to protect; only the **DES-1** primitive survives (regenerable and idempotent scaffolding, `reference/PRIMITIVES.md`). Copier is ONE eligible tool in the plan, not the platform (`ADR-012`). Historical text → | Copier owns `generated/` (100% overwritable), the engineer owns `domain/`; connection via inheritance/injection → an update does not overwrite human code | ADR-014 |
| I-6 | **Placement law** | each piece lives in the most deterministic substrate that can hold it; the model is the last resort; verdicts to the context, logs to disk | ADR-020 |
| I-7 | **Verdict bus** | every expensive operation emits a verdict ≤N lines + pointer; progressive disclosure (haiku triage → surgical slice) | `factory check`, D1 of CONTEXT |
| I-8 | **Memory as a repo artifact** | deterministic hooks write the journal from git+ledger (zero model narrative); cloning the repo = cloning the memory | ADR-019 |
| I-9 | **Narrative memory schema** | doc types = mutation semantics: STATE (overwrite), LOG (append), decisions/ (immutable), work/ (per-increment), reference/ (stable) | ADR-021 |
| I-10 | **RTM + evidence tree** | requirements with a stable id and `satisfied_by`; commits with station/spec-refs/proof-sha trailers; requirement↔station↔commit↔file matrix re-derived from artifacts | ADR-017/018 |
| I-11 | **Two-verifier doctrine** | re-derivation over custody: an external CI rebuilds the verdict on a clean runner and compares it against the pinned honest one; the only untouchable layer | ADR-022 |
| I-12 | **Deterministic shadow of the meta layer** | every narrative rule that must not be skipped has its own deterministic detector/blocker; judgment is never hard-blocked | ADR-023 |
| I-13 | **Honesty of limits** | HONEST-STATE / AUDIT as first-class artifacts; aspiration is never confused with reality; S0/M0 refuse rather than fabricate defaults | PF-8, HONEST-STATE.md |

> These 13 are the "Half B" of every factory-spec (§5): the Meta-Factory provides them
> standardized.
> What changes between factories is the "Half A" (the domain it manufactures).

## 4. Fundamental principles (inherited and extended)

We inherit PF-1…PF-8 from ASF (determinism where achievable; model-for-the-creative-part;
logic/substrate separation; prove-and-document-before-advancing; small checkpoints;
strict isolation; maximum safe automation; honesty of limits). We add:

- **PF-9 — Legitimacy of the fixed point.** Only the Meta-Factory applies itself to itself;
  every other factory is built from a more trustworthy layer (its Meta-Factory). Self-application
  = belonging to one's own product class (`VISION.md §2.2`).
- **PF-10 — Re-derivation over custody.** A stored artifact is not trusted: what's trusted is
  the ability to rebuild it identically on a clean runner. Replicable > archived (ASF/ADR-008).
- **PF-11 — Universal deterministic shadow.** Generalizes ADR-023: any obligation of
  any level that must not be skipped gets its own deterministic detector. The narrative declares,
  the code guarantees.
- **PF-12 — The orchestrator operates on interfaces.** The powerful model's long-lived context
  consumes specs/verdicts/reports/decisions; never raw implementation. The economy isn't
  total tokens: it's **resident tokens** (`CONTEXT-ECONOMY.md`).

## 5. The factory-spec: the SDD entry contract

A factory is defined by a **factory-spec** (machine-readable `factory.spec.yml` + prose
`docs/*.md`, whose canonical schema **the Meta-Factory defines**, not derived from any
factory). It has two explicit halves, just like ASF's spec had Half A / Half B —
but one level up:

```yaml
# factory.spec.yml  (ilustrativo, recortado)
factory: { name, slug, maturity }

# ── MITAD A: DOMINIO DE LA FÁBRICA (especificado por fábrica) ──
domain:
  produces: "sistemas agénticos de producción"        # qué fabrica esta fábrica
  target_framework: { name: langgraph, provider_agnostic: true }
  product_capabilities:                                 # el "sustrato" que la fábrica hornea en SUS productos
    - { id: observability, tools: [otel, langfuse], invariant: "span con provenance en cada decisión" }
    - { id: traceability,  tools: [neo4j, w3c_prov], invariant: "join key en cada nodo de linaje" }
    # ... (para ASF: las 7 capacidades; para Full-Stack: auth, ci, iac, ...)
  station_sequence:                                     # la línea de ESA fábrica (estaciones como dato, I-2)
    - { id: s00, name: "spec contract", activation: always }
    - { id: s01, name: "observability substrate", activation: always }
    # ... S2..Sn de la fábrica
  provision_modes: [prompt, integration, custom]        # niveles A/B/C por elemento (I-4)
  proof_check_types: [py_compile, deps, imports, pytest, ruff, mypy, topology, schema, substrate]

# ── MITAD B: SUSTRATO DE PRODUCCIÓN DE FÁBRICAS (estandarizado por el Meta-Factory) ──
factory_substrate:
  anti_rubber_stamp_column: true        # I-1 — no opcional, jamás
  verdict_bus:        { max_lines: 10 } # I-7
  generated_domain_boundary: true       # I-5
  memory_schema:      adr021            # I-8/I-9
  rtm:                { required: true }# I-10
  two_verifier_ci:    { rederive: true, pinned_verdict: true } # I-11
  placement_law:      true              # I-6
  context_budget:     { claude_md_max_lines: 120 } # PF-12

# ── REQUISITOS (espina SDD; cada uno con id estable + satisfied_by) ──
requirements:
  functional:
    - { id: REQ-F-001, statement: "...", satisfied_by: [s01] }
```

- **Half A** is specified per factory: it includes WHAT it manufactures, against which
  framework, what capabilities it bakes into its products, and what its station sequence is
  (which the Meta-Factory materializes as data, not code).
- **Half B** is where the Meta-Factory standardizes: the 13 invariants. Each key activates or
  parametrizes a meta-station. **They are not negotiable in their existence; they are in their
  parameter** (e.g. the bus's `max_lines`, not "is there a bus?").
- **Requirements** is the SDD spine (ADR-003): without requirements declared with a valid
  `satisfied_by`, M0 refuses. The RTM is re-derived from artifacts at the end (I-10).

## 6. The canonical meta-station sequence (building a factory)

The Meta-Factory line builds a **factory**. Each meta-station runs ASF's four phases
(Build → Test → Document → Gate) under the anti-rubber-stamp column (I-1).

| # | Meta-station | Builds in the new factory | Deterministic test (summary) |
| --- | --- | --- | --- |
| **M0** | Factory-spec contract (SDD) | nothing (validates the input) | schema + completeness + RTM closure (every requirement maps to an active station) |
| **M1** | Seed & column | the factory's trust kernel: verifier + 3 locks + deny-list | corrupting a verdict → the newborn factory rejects it (blocking proof) |
| **M2** | Engine & stations-as-data | the runner/gate/sequence (domain-agnostic) + the YAML of the declared sequence | with the same factory-spec, the order and route set are identical across runs |
| **M3** | Verdict bus & CLI | the `check`/`verify`/`gate`/`trace`/`rtm` verbs with bounded output | an injected failure shows as `file:line` in ≤N lines; the full log is on disk and NOT in the verdict |
| **M4** | Product template & generated/domain boundary | the factory's `template/` + `.copier-answers` + migrations + `domain/`'s `_skip_if_exists` | a domain file survives a re-scaffold (non-decorative boundary, I-5) |
| **M5** | Memory & RTM | the `docs/` tree (ADR-021 schema) + deterministic journal + evidence tree | `rtm` re-derives from artifacts: SATISFIED/PROVISIONAL/UNSATISFIED; the journal derives from git+ledger |
| **M6** | Two verifiers (external CI) | the re-derivation workflow + the pinned verdict + pre-push tripwire | a clean runner rebuilds the dummy and demands the pinned verdict; drift in either direction = red |
| **M7** | Harness (the factory's `.claude/`) | hooks = shadows of the column; agents = delegation contracts; commands = the operator's flow; CLAUDE.md ≤ budget | every prohibition in an agent has a shadow in a hook/CLI (I-12); residency budget measurable in the diff |
| **M8** | Anti-façade self-test (e2e) | — (runs the newborn factory over a minimal dummy product) | REAL scaffold + compile + run the dummy's gates in its own venv; **a green render is NOT enough** (ASF's façade-trap lesson) |

M8 is the most important gate and the one ASF learned late (AUDIT §"the two errors
compound"): **a factory is tested by really building a product, not by verifying that its
templates render.** Six bugs invisible to render+ast only appeared in ASF once
scaffolded+compiled. M8 makes it mandatory and un-skippable.

### 6.1 The dogfood: the Meta-Factory IS the output of its own line

The Meta-Factory is defined by the factory-spec `metafactory.spec.yml`, whose `domain.produces` is
*"factories"* and whose station sequence IS M0–M8. Running M0–M8 over that spec **produces the
Meta-Factory**. That is `VISION.md §3`'s fixed point made operational — and the only
legitimate self-application in the ecosystem (PF-9).

## 7. Repository structure and the trust hierarchy (Stages 0–3)

```
Meta_Factory/
├── seed/                          # ── STAGE 0: kernel de confianza, AUDITADO A MANO, CONGELADO ──
│   ├── verifier.py                #   el ÚNICO escritor de veredictos; computa passed desde exit codes
│   ├── column.md                  #   doctrina inmutable de los 3 cerrojos
│   └── external_ci.yml            #   el workflow de re-derivación (dos verificadores)
│   # Pequeño y legible. Cambiarlo = Nivel C siempre (consentimiento humano) + el seed VIEJO
│   # debe validar el seed NUEVO antes de promover (`SELF-IMPROVEMENT.md §3`).
├── src/metafactory/               # ── STAGE 1: la maquinaria (auto-mejorable bajo la columna) ──
│   ├── cli.py                     #   meta new | station | verify | check | trace | rtm | promote | improve
│   ├── engine/{station,sequence,runner,gate,run_context}.py
│   ├── verify/{checks/, report.py}   # report.py materializa el bus de veredictos (I-7)
│   ├── codegen/{copier_driver,answers,apply_station}.py
│   ├── spec/{model,loader,validator}.py + factory.schema.json   # la espina SDD (I-10, ADR-003)
│   └── stations/{_registry.yml, m00..m08.yml, templates/}        # las meta-estaciones (dato, I-2)
├── .claude/                       # ── el harness de CONSTRUCCIÓN del Meta-Factory ──
│   ├── settings.json              #   hooks (la columna) + permissions.deny
│   ├── commands/                  #   /meta-new, /meta-station, /meta-improve, /incremento
│   ├── agents/                    #   writer(sonnet), reviewer(sonnet|opus), triage(haiku), spec-analyst
│   └── hooks/                     #   proof_protect, gate_guard, stop_proof, commit_guard, post_edit_quality, session_journal, session_start
├── template/                      # ── EL TEMPLATE DE FÁBRICA: lo que toda fábrica HEREDA al nacer ──
│   └── factory/                   #   un chasis de fábrica COMPLETO: seed/ + src/<f>/ + .claude/ + template/ + docs/ + external CI
│       # Toda fábrica emitida ya trae los 13 invariantes cableados y verificados. Es el one-shot.
├── factories/                     # ── STAGE 2: fábricas producidas (aisladas) ──
│   ├── agent-systems-factory/     #   ASF regenerado como PRODUCTO (plug-in LangGraph) — ADR-006
│   └── full-stack-factory/        #   ejemplo de segunda fábrica (plug-in web stack)
│       # cada una con su PROPIO seed (heredado), sus gates, su CI externo. Stage 3 (sus productos)
│       # vive dentro de cada fábrica, fuera del sys.path del Meta-Factory (aislamiento, PF-6).
└── docs/                          # ── memoria narrativa del Meta-Factory (esquema ADR-021) ──
    ├── STATE.md · LOG.md · decisions/ · work/ · reference/
```

**Independence / trust hierarchy** (from ASF/ADR-022, extended to N levels; each layer is
more expensive and more trustworthy than the one below):

```
seed congelado (auditado a mano)
  > CI externo del Meta-Factory (otra máquina, re-deriva el dummy-fábrica)
    > columna del Meta-Factory (hooks/CLI, mismo actor)
      > CI externo de cada fábrica producida
        > columna de cada fábrica
          > gates de cada producto-de-fábrica
```

**Isolation (PF-6):** the Meta-Factory's machinery lives only in `src/metafactory/`; each
factory, only in `factories/<slug>/`. No factory is on the Meta-Factory's `sys.path`.
Verified by test (`test_metafactory_does_not_import_factories`), same as ASF.

## 8. The build harness and the gate→mechanism correspondence

The harness is **Claude Code**, built around its native primitives: **hooks** (the
determinism of the gates), **slash commands** (the operator's flow), **subagents** (the
creative slots and delegation), **skills**, and **settings** (including `permissions.deny`).
No invariant obligation depends on a natural-language instruction; it is materialized in
these primitives. Every produced factory inherits its own analogous harness (M7).

| Guarantee (one level up from ASF) | Primitive | Mechanism |
| --- | --- | --- |
| Not advancing a meta-station without the previous one gated | `PreToolUse` gate_guard (exit 2) | blocks `meta station` toward k if k-1's proof doesn't pass or the hash doesn't match |
| Verdict artifacts untouchable by the model | `PreToolUse` proof_protect + deny-list | denies writes to proof/ledger/rtm that don't come from the verifier |
| Not declaring a factory/station ready without proof | `Stop` stop_proof (exit 2) | re-runs verify of the current meta-station; blocks the turn if it fails |
| The commit doesn't attribute unproven work | `PreToolUse` commit_guard (exit 2) | requires trailers + referenced proof with passed=true + matching proof-sha |
| The orchestrator doesn't burn context on logs | verdict bus (CLI, not a hook) | `meta check` emits ≤N lines + path; the cheap path is the ergonomic one (the writer isn't punished) |
| The meta layer isn't skipped under pressure | deterministic shadow (I-12, PF-11) | for every narrative rule, a detector in a hook/CLI; judgment is never hard-blocked |

## 9. Anti-pattern prevention matrix (taken up a level)

| # | Anti-pattern | Structural mechanism that prevents it |
| --- | --- | --- |
| 1 | **A factory that self-fabricates outside its class** (ASF's error) | PF-9: only the Meta-Factory self-applies; ASF is regenerated as a product (ADR-006) |
| 2 | Green render taken for a functional product (façade-trap) | M8: real e2e mandatory (scaffold+compile+run), un-skippable |
| 3 | Meta layer governed by prose that gets skipped under pressure | PF-11 / I-12: universal deterministic shadow |
| 4 | Expensive orchestrator re-reading test dumps every turn | I-7 verdict bus; PF-12 interfaces, not implementation |
| 5 | Sub-delegation (Opus does what Sonnet should have done) | ergonomic delegation + model routing as data (`CONTEXT-ECONOMY.md`) |
| 6 | Rubber-stamped gates | I-1 column: verdict not writable by the model, hash recomputed, Stop re-runs |
| 7 | Domain identity hardcoded into the factory's code | I-2 stations as data; domain specifics live in the factory-spec |
| 8 | Trusting an artifact that no one can re-derive | PF-10 / I-11: re-derivation over custody in external CI |
| 9 | Self-improvement that corrupts its own trust chain | trust hierarchy (§7) + blast-radius gate (`SELF-IMPROVEMENT.md`) |
| 10 | Requirements "fulfilled" by narrative, not by evidence | I-10 RTM re-derived from artifacts; UNSATISFIED cuts the CI |

## 10. First proposed increment

The minimal bootstrap that demonstrates the end-to-end fixed point is governed in
`docs/work/BOOTSTRAP-INCREMENT.md`. In summary: hand-write the **seed** (Stage 0) and the
base machinery (CLI + engine + verifier with the verdict bus + factory-spec validator);
meta-stations M0–M3 + M8; the `template/factory/` bounded to those stations; the column's
hooks with `permissions.deny`; and the factory-spec of a minimal **dummy-factory**. Acceptance
criterion = **blocking demonstration**: corrupting the column's invariant in the dummy,
the test fails, the gate doesn't open, the `Stop` hook blocks the turn, and the external CI
re-derives a different verdict. Only once that is proven is ASF regenerated as a product (ADR-006).
